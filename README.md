# 🏢 잠실 센트럴 프라임 공인중개사사무소 공식 홈페이지

서울시 송파구 잠실동 전문 프리미엄 공인중개사사무소를 위한 모바일 최적화 인터랙티브 웹사이트입니다.

## ✨ 주요 기능 및 특징

1. **최신 트렌드 반영 UI/UX 디자인 (ui-ux-pro-max 적용)**
   - 프리미엄 다크/라이트 모드 테마 전환 지원 (로컬 스토리지 연동)
   - 모바일 퍼스트 반응형 레이아웃 (375px ~ 1440px+ 최적화)
   - 실시간 시세 및 거래 동향 브리핑 롤링 티커

2. **잠실 대단지 랜드마크 아파트 탐색기**
   - 단지별 카테고리 필터링 (잠실 엘스, 리센츠, 트리지움, 레이크팰리스, 파크리오, 잠실래미안아이파크/잠실르엘/주공5단지)
   - 평형, 구조, 층수, 추천 이유, 세부 스펙 및 갤러리 모달 뷰어 제공

3. **부동산 소식 & 전문가 분석 뉴스룸**
   - 잠실 시세동향, 재건축·정비사업, 정책·세무·대출 가이드, 인프라 개발호재 카테고리 분류
   - 실시간 검색 및 마크다운 기반 전문 아티클 모달 리더
   - 주간 부동산 브리핑 뉴스레터 구독 기능

4. **부동산 스마트 모의 계산기**
   - 국토교통부 법정 상한요율 기준 **중개보수(복비) 계산기** (매매/임대차, VAT 10% 토글)
   - 송파구 조정대상지역 기준 주택수별 **취득세 모의 계산기**

5. **원터치 전화연결 및 1:1 방문 상담 예약 CTA**
   - 즉시 통화 연결 버튼 (`02-421-8949`)
   - 모바일 전용 하단 고정 액션바 (전화연결, 카카오톡 1:1 상담, 상담예약)
   - 1:1 방문/전화 상담 예약 폼 및 위치/약도 안내 (잠실새내역 5번 출구)
